Função cmtcPtoQ¶

Converte a matriz de transição de um passo (P) para a matriz Q

In [4]:
def cmtcPtoQ(P, Mu):
    [r,c] = P.shape
    Q = np.empty_like(P)
    if ((r != c) | np.any(np.sum(P, 1) != 1)):
        raise Exception('Matriz P invalida!')

    for x in range(0, r):
        Q[x, :] = Mu[x] * P[x, :]
        Q[x, x] = -np.sum(Q[x, :])
    return Q

Exercício 1¶

Implementar uma função cmtcP para calcular o estado permanente de uma cadeia de Markov em tempo contínuo.
A função recebe como argumento a matriz de probabilidades de um passo (P)

Algoritmo:

  • Testa se a matriz está corretamente construída
    Matriz quadrada e valores de uma linha tem que somar 0
  • Calcula matriz A
    A = Transposta(Q)
    A = A concatenada com vetor de 1s de tamanho n (usar np.vstack para concatenar)
  • Calcula vetor B
    B = vetor de zeros de tamanho n concatenado com [1]
  • Calcular o vetor PI
    Usar a função np.linalg.pinv para calcular A_pinv
    Usar a função np.dot para multiplicar A_pinv e B
In [5]:
def cmtcP(Q):
    [r,c] = Q.shape
    # A matriz que deve duas minensões iguais
    # A soma das linhas deve ser igual a 0
    # Na construção da matriz podem ser gerados valores cuja soma é muito próxima de zero
    # Testar se o valor da soma é muito próximo de zero
    if ((r != c) | (not np.all(np.isclose(np.sum(Q, 1),0)))):
        raise Exception('Matriz Q invalida!')

    # Coloque seu código aqui
    # A = Transposta(Q) concatenada com uma linha de 1s (condição de normalização)
    A = np.vstack((Q.T, np.ones(r)))
    # B = vetor de zeros de tamanho n concatenado com [1]
    B = np.concatenate((np.zeros(r), [1]))
    # PI = pseudo-inversa(A) . B  (solução de PI.Q = 0 com soma(PI) = 1)
    A_pinv = np.linalg.pinv(A)
    PI = np.dot(A_pinv, B)

    return PI

Exercício 2¶

Um dispositivo pode estar em cinco estado: (0) desligado, (1) em aquecimento, (2) em operação, (3) em esfriamento, e (4) em manutenção. O dispositivo passa em média 40 minutos desligado. Sempre que é ligado, o dispositivo vai para aquecimento, onde permanece em média por 20 minutos. Depois do aquecimento o dispositivo vai para operação normal, exceto quando ocorre um problema e precisa ir para manutenção. A probabilidade de o dispositivo em aquecimento precisar de manutenção é 0,08. O dispositivo permanece em operação em média por uma hora, indo para o esfriamento antes de desligar. Também é possível que o dispositivo em funcionamento precise ir para manutenção, o que ocorre com uma probabilidade de 0,12. O dispositivo permanece em média por 10 minutos em resfriamento antes de ser desligado. A probabilidade de o dispositivo em resfriamento precisar de manutenção é 0,04. O tempo médio para dar manutenção ao dispositivo é de 30 minutos. Quando a manutenção termina o dispositivo vai para o estado desligado. Que proporção do tempo o dispositivo permanece em operação?

Taxas de permanência¶

  • Tempo médio de permanência no estado 0 (desligado) = 40
  • $\mu_{0}$ (taxa de permanência no estado 0) = 1/40
  • Tempo médio de permanência no estado 1 (em aquecimento) = 20
  • $\mu_{1}$ (taxa de permanência no estado 1 = 1/20
  • Tempo médio de permanência no estado 2 (em funcionamento) = 60
  • $\mu_{2}$ (taxa de permanência no estado 2 = 1/60
  • Tempo médio de permanência no estado 3 (em resfriamento) = 10
  • $\mu_{3}$ (taxa de permanência no estado 3 = 1/10
  • Tempo médio de permanência no estado 4 (em manutenção) = 30
  • $\mu_{4}$ (taxa de permanência no estado 4 = 1/30

Probabilidades de transição¶

  • $p_{01}$ (probabilidade de o dispositivo desligado ir para aquecimento) = 1
  • $p_{14}$ (probabilidade de o dispositivo em aquecimento precisar de manutenção) = 0,08
  • $p_{14} + p_{12}=1$
  • $p_{12}$ (probabilidade de o dispositivo em aquecimento não precisar de manutenção) = 1 - 0,08 = 0,92
  • $p_{24}$ (probabilidade de o dispositivo em operação precisar de manutenção) = 0,12
  • $p_{24} + p_{23}=1$
  • $p_{23}$ (probabilidade de o dispositivo em aquecimento não precisar de manutenção) = 1 - 0,12 = 0,88
  • $p_{34}$ (probabilidade de o dispositivo em resfriamento precisar de manutenção) = 0,04
  • $p_{34} + p_{30}=1$
  • $p_{30}$ (probabilidade de o dispositivo em aquecimento não precisar de manutenção) = 1 - 0,04 = 0,96
  • $p_{40}$ (probabilidade de o dispositivo em manutenção ir para o estado desligado) = 1

Resposta¶

O dispositivo permanece em operação (estado 2) cerca de 42,5 % do tempo ($\pi_2 = 0{,}4247$ com as taxas exatas).

Observação sobre a resposta esperada¶

A resposta indicada no enunciado ([0.30799585 0.15399792 0.4241859 0.06235533 0.05146501]) usa as taxas arredondadas da tabela de taxas de transição ($\mu_{23}=0{,}0147$ e $\mu_{24}=0{,}0020$, ou seja $\mu_2 \approx 0{,}0167$ em vez de $1/60 = 0{,}016667$). Com as taxas exatas o resultado é $\pi_2 = 0{,}4247$; com $\mu_2 = 0{,}0167$ o resultado coincide com o esperado até a 4ª casa decimal ($\pi_2 \approx 0{,}4242$). Nos dois casos, o dispositivo fica cerca de 42 % do tempo em operação.
